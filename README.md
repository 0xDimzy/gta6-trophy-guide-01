Leonida Trophy Guide — an offline, open-source GTA VI trophy guide and tracker for PlayStation 5: all 55 official trophies with a guide in our own words citing its sources, a roadmap to the platinum, missable flags, and a checklist tracker (localStorage, export/import, filters by kind, spoiler setting) that works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
